## 🚀 Building now: [**REGEN**](https://github.com/sameernagar-hub/regen-engine), the job engine that keeps receipts

**🎯** Auto-apply tools spam the same resume and *invent* answers.<br>
**🔧** I built an open-source engine in Docker: it polls **5,000+ company boards** at the source, writes a **truthful one-page resume per job** from provable facts, applies with a fleet of workers, and saves a **confirmation screenshot for every submit**.<br>
**📈** **165 applications** with proof · best day **49** · **$0** model cost (driven over **MCP**) · **13 merged release PRs** in under 2 weeks · [**▶ watch it live**](https://regen-engine.onrender.com)
